## General Discussions/checklist
-> To transfer getup from sim2real, we can only use realistic available data for actor, hence if we want policy that can take in target height, there are ways to achieve this.
  -> One easy way if to have theta, theta_dot, gravity, gyro, last action in theactor. Critic will see the true base height, base lin vel, contacts etc. Reward is based on true base height but probably it will learn to estimate heights from data. Also its good to stack history here, 3-5 past history
  -> Thesis-grade idea is to actually come up with an implicit Fk based estimator or an online height estimator that you can use to actually use to condition the policy on. This small network is regressed on actual height based on observations/
